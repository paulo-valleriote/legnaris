# AGENTS.md — backend/internal/sheet/template (DAG, Registry, Templates)

## Rules

- **Templates are code, not DB** — no `template` collection; `BuildRegistry` freezes templates and DAGs at boot. `Registry.List`/`FetchByID` return deep copies; resolve DAGs through `Registry.DAG` (the `sheet.DAGProvider` interface), never a map accessor.
- **DAGs are immutable after boot** — the mutex is private. Read through `HasNode`/`GetNode`/`GetChildren`/`ValidateUpdateKeys`, or stay under the single lock `Recalculate`/`NormalizeAndRecalculate` takes. Never nest a locking call under `Recalculate` (recursive `RLock` deadlocks with a queued writer; `TestRecalculate_ValidationRunsUnderSingleReadLock`).
- **Use `NormalizeAndRecalculate` for PATCH** — one lock covers editability, exclusive normalization and recalculation. Do not compose `ValidateUpdateKeys` + `NormalizeExclusiveUpdates` + `Recalculate` in production. Unknown key/prefix → `UnknownFieldError` (400 `UNKNOWN_FIELD`); derived leaf → `NotEditableError`; non-numeric exclusive member → `ExclusiveValueTypeError`; two members on → `ExclusiveGroupConflictError`. `Create` may call `Recalculate` directly because it seeds derived fields too.
- **Keys cannot collide** — DAG keys are dotted (`stats.dexterity`); engine env keys use underscores (`stats_dexterity`). Every segment must match `^[A-Za-z][A-Za-z0-9]*$`; never relax it (`TestBuildDAG_FieldNameValidation`).
- **Change detection is relative** — `maputils.Equal` uses a 1e-9 relative epsilon, so absolute slack grows with magnitude and integers above 2^53 collapse in `float64`. Do not use it for exact currency/XP arithmetic; a no-op update cascades nothing and does not repair stale derived values.
- **Depth is capped at 5** — `maputils.FlattenPathKeys`/`ToEngineEnv` return `ErrMaxDepthExceeded`; the service maps it to 400.
- **Formulas and `DependsOn` must match** — `BuildDAG` checks declared deps exist, not that every identifier a formula reads is declared; an undeclared read evaluates against `0.0`. Keep `TestFantasyV1_FormulaReferencesMatchDependsOn` green. Text leaves never carry formulas.
- **Seed by type** — `FieldSchema.SeedValue()` is `""` for text, `false` for bool, otherwise `Default`. The DTO `default` stays numeric for every type, so a text leaf showing `0` is expected.
- **`config` vs `rules`** — `config.*` leaves are 0/1 wiring flags (the web renders any `config` first segment as a toggle). Tuning numbers live in `rules` and are read by formulas.
- **Order is presentation** — `SectionOrder` and nested `Order` drive the DTO; stored layouts are keyed by name and survive a reorder. Ghost or duplicate entries are skipped; unlisted keys fall back to alphabetical.
- **Row keys mirror the web** — `SectionRowKeys` is the only backend definition of a valid Layout key and must change with `web/src/engine/field_grouping.ts`: lone leaf path, table group path, `<parent>#<exclusive_group>`. `ValidateLayout(tmpl, sectionOrder, pinned)` takes plain lists and returns `UnknownLayoutSectionError`, `UnknownLayoutRowError` or `DuplicateLayoutKeyError`.
- **Boot validators** — `BuildRegistry` runs `ValidateDiceDefaults`, `ValidateGenerationMetadata` and `ValidateNameLeaf`; a bad template fails boot. Keep the pinned `fantasy_v1` seed tests current. Dice defaults are read-only template data and are never written to a Sheet; a Section default must fit at least one Row of that Section, and a table Row needs `@.<column>` because the Row key is not a Field.
- **Generation metadata** — `Generatable`, `GeneratableKinds` and `PreferDefault` are optional flags; `Min`/`Max`/`MaxLength` are pointers so "unset" differs from 0. `ValidateGenerationMetadata` rejects a generatable non-editable leaf, an inverted range, bounds on a non-number, a non-positive or non-text length limit and an out-of-range `PreferDefault`. Only the generation validator reads the bounds; PATCH and preview do not enforce them.
- **Template IDs are slugs** — `FetchTemplate` rejects anything outside `^[a-z][a-z0-9_]*$` before the registry lookup, so junk is 400, not 404.
- **Errors** — declare typed errors here; never import `apperr`. Wrap with `%w`; translate at the service boundary. `ErrTemplateIDNotProvided` and `ErrTemplateIDInvalid` are 400 at both boundaries.
